➕ Añadir Nuevos Ejercicios

¡Es muy fácil! No necesitas tocar el código:

1 Abre cualquier archivo JSON en la carpeta data/
2 Copia el formato de un ejercicio existente
3 Modifica con tu nuevo caso: id, título, problema, opciones, explicación
4 ¡Guarda y recarga! El ejercicio aparecerá automáticamente
⚠️ Importante: El campo nivel debe ser exactamente: "básico", "intermedio" o "avanzado" (minúsculas, con tilde en básico)

🎯 Estructura de un Ejercicio

Cada ejercicio en JSON tiene estos campos:

  • id - Identificador único (ej: "plc-007")
  • area - Área formativa
  • nivel - básico | intermedio | avanzado
  • titulo - Nombre del problema
  • contexto - Situación industrial
  • problema - Síntomas del fallo
  • datos_tecnicos - Información técnica
  • opciones - Array de posibles diagnósticos
  • respuesta_correcta - Índice de la opción correcta (empieza en 0)
  • explicacion - Solución técnica detallada

📁 Estructura de Archivos

  • index.html - Página principal
  • css/style.css - Estilos de la aplicación
  • js/loader.js - Carga de ejercicios desde JSON
  • js/app.js - Lógica de la aplicación
  • data/ - Carpeta con ejercicios en JSON
  • README.md - Documentación completa

💡 Consejos para Formadores

  • Usa ejercicios básicos para evaluación diagnóstica
  • Crea ejercicios progresivos: básico → intermedio → avanzado
  • Basa los ejercicios en casos reales de tu experiencia
  • Las explicaciones deben ser técnicas y profesionales
  • Incluye datos técnicos precisos (modelos, tensiones, etc.)
💾 Sistema de Progreso: La plataforma guarda automáticamente los ejercicios completados en el navegador (localStorage). No se pierden al cerrar.

🎨 Personalización

Puedes personalizar fácilmente:

  • Colores: Edita variables CSS en style.css
  • Áreas: Crea nuevos archivos JSON en data/
  • Ejercicios: Añade, modifica o elimina en los JSON
  • Niveles: Mantén los 3 niveles estándar

🔧 Soporte Técnico

¿Problemas?

  • Abre la consola del navegador (F12) para ver errores
  • Verifica que los JSON tengan sintaxis correcta
  • Comprueba que las rutas de archivos sean correctas
  • Lee el README.md para solución de problemas comunes
